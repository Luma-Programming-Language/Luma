# Luma editor clients

Luma's language server communicates over stdio. Each client here starts the
installed `luma` executable with `--lsp`.

- [Neovim](./neovim/README.md)
- [Emacs](./emacs/README.md)
- [Zed](./zed/README.md)
- [Visual Studio Code](./vscode/README.md)

Make sure `luma` is on your `PATH`, or configure the editor client with the
path to your Luma executable.
